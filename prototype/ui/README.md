# UI prototype

Open `index.html` directly in a browser. The prototype demonstrates visual hierarchy and interaction direction; it is not the production standalone application.

Implemented interactions:

- animated visual sources;
- rig 10/14 switch;
- fixture sampling and semantic readout;
- source/executor selection;
- momentary flash and blackout;
- output arm state;
- semantic profile editor dialog;
- JSON prototype export/import.

Production code must follow `docs/VISUAL_DESIGN_SYSTEM.md` and share the C++ engine with the VST3.
